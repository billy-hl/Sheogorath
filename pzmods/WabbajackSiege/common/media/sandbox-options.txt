VERSION = 1,

/*
 * Every setting this mod has, as sandbox options.
 *
 * WHY HERE AND NOT IN A CUSTOM MENU
 * These used to live in a bespoke store (ModData + a packet + a generated
 * right-click submenu). This is where the rest of the world puts them: 100 of
 * the mods installed on this server ship a sandbox-options.txt, and staff reach
 * them at Admin Panel -> Sandbox Options like any other mod's. The right-click
 * menu is now events only.
 *
 * THIS FILE IS THE ONLY SOURCE OF DEFAULTS.
 * WabbajackSettings.lua maps dotted keys onto these names and carries a fallback
 * for each, used only when SandboxVars is unavailable. If you change a default,
 * change it here first - two copies of a default is how they drift.
 *
 * Ranges replaced the old fixed choice lists. The lists existed because a
 * right-click submenu can only offer discrete options; a sandbox slider has no
 * such limit, so each min/max spans what the old list offered end to end.
 *
 * Raid protection is first because it is the feature currently under test.
 */
